# Competências

Esta pasta guarda uma nota por competência do framework de competências da sua organização.

## Como funciona

1. **Crie** uma nota de competência usando o template `Competency Note`
2. **Conecte** as notas de trabalho às competências na seção `## Related` delas
3. **A evidência se acumula via backlinks** — abra qualquer nota de competência e veja no painel de backlinks todo o trabalho que a demonstra
4. **O Registro de Conquistas** agrega a evidência por trimestre em seções `#### Competency Evidence`
5. **O Review Template** estrutura a autoavaliação em torno das competências

## Campos de frontmatter

- `current-level` — o nível em que você se avalia nesta competência
- `target-level` — onde você quer chegar

## Dicas

- Não mantenha listas de evidência na mão dentro das notas de competência — deixe os backlinks fazerem o trabalho
- Anote o contexto ao criar o link: `[[Nome da Competência]] — o que foi demonstrado`
- Revise os backlinks das competências ao se preparar para uma avaliação de desempenho
