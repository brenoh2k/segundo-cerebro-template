# Espaço de Pensamento

Rascunho do Claude para raciocinar, esboçar e destrinchar problemas antes de fixar conclusões nas notas de trabalho.

## Como Funciona

- As notas daqui são **rascunhos de trabalho**, não resultado final
- Nomeadas com data e contexto: `AAAA-MM-DD-nome-descritivo.md`
- Depois que as conclusões chegam a uma nota de trabalho ou registro de decisão, as notas de pensamento permanecem como referência
- Versionadas no git, para portabilidade entre máquinas

## Quando Usar

- Analisar um problema complexo antes de escrever um [[Decision Record|Registro de Decisão]]
- Rascunhar conteúdo que será refinado em uma nota de trabalho
- Raciocinar sobre trade-offs e alternativas
- Registrar pesquisa intermediária antes de sintetizar

## Convenção de Links

- As notas de pensamento apontam para a nota de trabalho ou decisão que alimentam, pela seção `## Alimenta`
- A nota final aponta de volta para a nota de pensamento, formando a trilha de auditoria
